# stock-alert-editor

株価アラートの監視ルール（ウォッチリスト）をブラウザから編集するためのエディタです。
`index.html` の1ファイルだけで動きます。

## これは何か

GitHub リポジトリに置かれた `watchlist.json` を読み書きするための画面です。
一覧表示・追加・編集・削除ができ、変更はそのままリポジトリにコミットされます。

このリポジトリには**データは一切含まれません**。監視している銘柄やしきい値は、
利用者が自分のアクセストークンで自分のリポジトリから読み込みます。
トークンは利用者のブラウザの中だけに保存され、送信先は `api.github.com` のみです。

## 使い方

1. 公開ページを開く
2. 「リポジトリ」に `owner/repo`、「アクセストークン」に Fine-grained personal access token を入力
   （対象リポジトリを1つに絞り、権限は Contents: Read and write のみで十分です）
3. 「接続して読み込む」

## 対応している条件

価格の上抜け・下抜け／％変動（前日比・任意期間）／52週高値からの下落率／
移動平均線（50日・200日）の上抜け・下抜け／出来高の急増。
